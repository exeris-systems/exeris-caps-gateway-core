# ADR-088 — Cryptographic License Manifest and Offline Verification (link stub)

**Authoritative copy:** [`exeris-docs/adr/ADR-088-cryptographic-license-manifest-and-offline-verification.md`](https://github.com/exeris-systems/exeris-docs/blob/main/adr/ADR-088-cryptographic-license-manifest-and-offline-verification.md)

ADR-088 defines the signed licence manifest and its offline verification at boot.

## Why this stub exists

`exeris-caps-gateway-core` is a `commercial` capability. Its production use is gated by a signed licence manifest that the kernel verifies offline; `GatewayCoreEntitlement` registers the `EntitlementRequirement` that the manifest must satisfy.
