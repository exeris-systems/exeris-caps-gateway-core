# ADR-023 — Capability Licensing Taxonomy (link stub)

**Authoritative copy:** [`exeris-docs/adr/ADR-023-capability-licensing-taxonomy.md`](https://github.com/exeris-systems/exeris-docs/blob/main/adr/ADR-023-capability-licensing-taxonomy.md)

ADR-023 defines the three-valued licensing taxonomy for capabilities: `community`, `commercial`, and `enterprise-private`.

## Why this stub exists

`exeris-caps-gateway-core` is licensed as `commercial` (Exeris Commercial License, source-available): the source can be read, built, tested and evaluated, and production use requires a commercial licence. Its entitlement id is `exeris-caps-gateway-core`, equal to its artifactId.
