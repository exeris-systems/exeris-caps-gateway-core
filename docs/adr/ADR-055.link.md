# ADR-055 — Cap-Tier Wall Guard (link stub)

**Authoritative copy:** [`exeris-tooling/docs/adr/ADR-055-cap-tier-wall-guard.md`](https://github.com/exeris-systems/exeris-tooling/blob/main/docs/adr/ADR-055-cap-tier-wall-guard.md)

ADR-055 implements the bytecode scan that enforces the Cap-Tier Wall at `process-classes` via `exeris:verify-capabilities`.

## Why this stub exists

`CapTierWall` inspects the compiled classes of this repository and derives `own cap(s): [gatewaycore]` from `eu.exeris.caps.gatewaycore`. It guarantees that no forbidden packages (Spring, Netty, servlets, kernel internals, or sibling cap internals) are imported.
