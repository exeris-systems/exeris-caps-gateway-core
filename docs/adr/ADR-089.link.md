# ADR-089 — Capability Entitlement Enforcement and Runtime Contract (link stub)

**Authoritative copy:** [`exeris-docs/adr/ADR-089-capability-entitlement-enforcement-and-runtime-contract.md`](https://github.com/exeris-systems/exeris-docs/blob/main/adr/ADR-089-capability-entitlement-enforcement-and-runtime-contract.md)

ADR-089 defines how a capability declares an entitlement and how the kernel enforces it at runtime.

## Why this stub exists

`exeris-caps-gateway-core` registers one `EntitlementRequirement` through `META-INF/services`, with entitlement id `exeris-caps-gateway-core` equal to its artifactId; `GatewayCoreLicenceEnforcementTest` checks the requirement against signed manifests that do and do not entitle that id.
